## What's new

- **msync**: Windows events, mutexes and semaphores use Mach semaphores instead of a round trip through Wine's
  server. Games that use many threads spend less time waiting. AnvilMac turns it on for game launches; Game Settings
  can turn it off per game.

## Measured

- Console test on an M2 Pro under Rosetta 2: event set 7.7 to 0.38 microseconds; five pairs of threads handing off
  73.9 to 9.9 microseconds.
- Played on this runtime by the owner: SPORE, Mothville, Keyboard Chaos.

## Known problems

- msync makes thread synchronization cheaper, not every slowdown: Bink videos in the ReXGlue ports (Naruto) stay slow.
  That is an issue in the ports and has been reported to them.
